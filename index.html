Io decido. Claude accelera.

Uso Claude, l'AI di Anthropic, ogni giorno, soprattutto Claude Code dal terminale. Mi aiuta a scrivere codice, test e revisioni. Il design, le scelte e la qualità finale restano mie.

  1. Ascolto e ricerca

    Parlo con chi userà il sito. Cosa vende, a chi, cosa non funziona oggi. Guardo come lavorano i migliori del settore.

    Io

  2. Design system

    Prima di scrivere codice fisso colori, font, spazi e movimento. Così ogni pagina sembra parte dello stesso progetto.

    IoClaude

  3. Sviluppo con Claude Code

    Descrivo cosa serve, Claude scrive una prima versione, io la rivedo e la correggo. Quello che prima richiedeva giorni ora richiede ore.

    IoClaude Code

  4. Test e revisione

    Test unitari ed end-to-end con Playwright, controllo da telefono e accessibilità. Ogni modifica passa da una pull request.

    IoClaude

  5. Online e manutenzione

    Pubblico su Vercel, collego il dominio e spiego al cliente come aggiornare i contenuti da solo.

    Io
